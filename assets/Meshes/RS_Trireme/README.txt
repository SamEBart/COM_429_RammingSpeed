This is the finalized model for the Ramming Speed Trireme.

Within the RS_Trireme.glb file, you will find the following models, which can be enabled or disabled as needed:
Hull
Masts
Front Sail Furled
Front Sail Unfurled
Back Sail Furled
Back Sail Unfurled
Left Oars
Broken Left Oars
Right Oars
Broken Right Oars

Inside of the RS_TriremeTexture folder, you will find a material called TriremeMat. This material is intended to be applied to the Trireme's attachments (catapult/ballista,) in addition to the Trireme itself.

The material has a parameter called "Base Color Tint," which alters the hue of the eyes and bright trim of the ship. Ideally, this parameter will be altered on a per-ship basis, reflecting the color of the faction that ship belongs to.

NOTE: Animations are not included in this folder. We plan to add them later down the line.
